02 / BEHIND THE NUMBERS
Correct is necessary.
Efficient deserves a test, too.
01
Keep the data identical.
Two copies of 1,000 synthetic orders. Same merchant, same sorting, same expected results. One copy has a lookup index.
02
Measure actual work.
D1 returns the number of rows it read. That includes work to find the answer, not just the orders displayed on the page.
03
Make a checkable decision.
Compare the full returned orders, then check the candidate against a 100-row budget. A cheaper, incorrect answer still fails.
THE TRADEOFF
An index can reduce reads, but adds storage and work when data changes. This is a controlled read experiment—not a production benchmark, a dollar-savings estimate, or a spending cap.
