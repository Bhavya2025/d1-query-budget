          02 / The Method
          

            Correct is necessary.
Efficient deserves a test.
          

          

            A small experiment with a strict rule:
a cheaper wrong answer
            never passes.
          

        

        

          

            01
            

              
Hold the Data Constant

              

                Two copies of 1,000 synthetic orders. Same merchant, same
                sorting, same expected results. One table has a lookup index.
              

            

          

          

            02
            

              
Measure the Database Work

              

                D1 reports how many rows it reads to find the answer. That can
                be far more than the number of orders it returns.
              

            

          

          

            03
            

              
Check Both Sides of the Tradeoff

              

                Compare every returned field and its order. Then check reads
                against the 100-row budget. Both checks must pass.
              

            

          

        

      

      

        A Note on Indexes
        

          An index can reduce reads, but adds storage and work when data
          changes. These results describe a synthetic read workload, not
          production savings or a spending cap.
